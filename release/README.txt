Trackly · 学习监督系统
======================

⚠️ 仅供个人/家庭使用，严禁商业行为

快速开始（手把手）:
  Mac：右键 Trackly.app → 打开（仅首次）→ 浏览器自动弹出
  Windows：双击 supervised-learning-win.exe

  如弹出"无法验证"提示：右键 app → 选「打开」→ 点「打开」即可。
  之后双击正常启动。

iPad / iPhone 怎么用:
  1. 连同一 WiFi
  2. Safari 打开 http://电脑IP:3001/dashboard?userId=你的名字
  3. 分享 → 添加到主屏幕 → 像 App 一样用

── 通知配置 ──

微信通知（免费，不需要服务器）:
  1. 打开 sct.ftqq.com → 微信扫码 → 复制 SendKey
  2. 在仪表盘「推送设置」页面直接填

飞书通知（免费，不需要服务器）:
  1. 飞书群 → 群设置 → 群机器人 → 添加自定义机器人
  2. 复制 Webhook 地址 → 在仪表盘「推送设置」页面直接填

iPad 快捷指令配置: 见 README.md
