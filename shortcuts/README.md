# iPad 快捷指令配置指南

## 概述

通过 iOS 快捷指令自动化，在打开/关闭学习 App 时自动上报到监督后端。

## 前置准备

1. 后端已部署运行（局域网或公网可访问）
2. 获取 API Token（在 `.env` 中配置的 `API_TOKEN`）
3. iPad 安装 **快捷指令** App（系统自带）

## 配置步骤

### 1. 创建"打开 App"自动化

为每个学习 App 分别创建：

1. 打开**快捷指令** App → 底部点"自动化" → 右上角"+" → "创建个人自动化"
2. 选择 **App** 触发器
3. 勾选 **"已打开"**，选择目标 App（如"新东方大学考试"）→ 点"完成"
4. 点"下一步"，添加以下动作：

#### 动作 1：获取当前时间
- 搜索"**当前日期**"，添加

#### 动作 2：发送到后端
- 搜索"**URL**"，添加
- 方法：**POST**
- URL：`http://你的服务器IP:3001/api/v1/tracking/push`
- 头部：
  - `Content-Type`: `application/json`
  - `Authorization`: `Bearer 你的API_TOKEN`
- 请求体：
```json
{"userId":"student-1","action":"start","appName":"新东方大学考试","timestamp":"{{当前日期}}"}
```

5. 点"下一步"，**关闭"运行前询问"** → 点"完成"

### 2. 创建"关闭 App"自动化

步骤同上，但：
- App 触发器选 **"已关闭"**
- 请求体中 `action` 改为 `"end"`：
```json
{"userId":"student-1","action":"end","appName":"新东方大学考试","timestamp":"{{当前日期}}"}
```

### 3. 为所有学习 App 重复配置

需要配置的 App（每个 App 2 个自动化 = 共 6 个）：

| App | 用途 |
|-----|------|
| 新东方大学考试 | 英语考试学习 |
| 小鹅通学员版 | 在线课程 |
| 网易有道词典 | 查词学习 |

## 验证

1. 打开目标 App 并等待 5 秒
2. 关闭 App
3. 在监督者仪表盘中查看追踪记录：`http://服务器IP:3001/dashboard?userId=student-1`

## 时间戳格式说明

快捷指令中的 `{{当前日期}}` 需要格式化为 ISO 8601。如果默认格式不对，添加"格式化日期"动作：
- 日期格式：自定义
- 格式字符串：`yyyy-MM-dd'T'HH:mm:ss`

## 故障排查

| 问题 | 解决 |
|------|------|
| 快捷指令未触发 | 检查自动化是否启用、是否关闭"运行前询问" |
| 后端未收到数据 | 检查 iPad 与服务器在同一网络、API Token 正确 |
| 时间戳不对 | 检查日期格式化动作配置 |
